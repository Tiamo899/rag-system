## 在 rag-system 中使用

1. 在系统「知识库」中创建一个知识库，可设置分块大小（默认 500 token）与重叠度（默认 50）。
2. 上传上述任一 .docx 文档，系统自动解析、按标题层级（#/##/###）分块并向量化。
3. 每份文档以章节标题作为分块标题，可在检索结果中直接溯源到“第X章”。
